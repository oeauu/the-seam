# The Seam

The Seam 是一个以空间和时间浏览历史人物、事件与相关史料的数字档案项目，采用 React、TypeScript、Vite、Three.js 和 D3。身份与主题标签不再控制导航、排序或坐标。

## 浏览功能

- 白色三维地球仪、深色国境线、金色档案坐标，支持旋转与缩放。
- 点击国家先聚焦，再进入可平移、缩放的二维地图；返回保留观察位置与缩放。
- 随缩放改变坐标聚合；同坐标的多条档案通过选择列表访问。
- 右侧非模态档案面板与地图、时间轴同时可用；手机使用底部面板。
- 时间范围按档案和当前年份确定，支持拖动、键盘单年调整与恢复全部时期。收起或重新展开均显示全部时期。
- 档案检索与「地点待考」入口；三维不适用时可使用二维国家选择和档案索引。
- `/record/:slug` 与 `/country/:id` 可直接访问，浏览器前进后退同步页面。旧 `entry-*` 档案链接仍可使用。

## 开发

```sh
npm install
npm run dev
npm run build
npm run lint
npm run test
npm run test:e2e
```

如需运行端到端测试但尚未安装 Chromium，可运行 `npx playwright install chromium`。

## 投稿配置

复制 `.env.example` 为 `.env.local`，将 `VITE_SUBMISSION_EMAIL` 设为真实官方邮箱后重新启动或构建。未配置时显示「投稿邮箱尚未公布」，禁用复制与撰写，不使用默认或虚构邮箱。撰写邮件只调用邮件客户端，并不表示邮件已经发送或档案已经收录。

## 内容状态与迁移

`src/data/records.ts` 保留重构版的 13 条档案。`src/data/legacy/` 完整保留重构前 `d475573` 的 11 条原始档案稿与 17 条演示事件原稿，包括正文、来源和贡献者。旧事件未经逐条核查，在 `src/data/archive.ts` 中保留为待考记录：原稿年代照录，可靠年代与坐标为空，可通过索引、地点待考或旧分享链接查阅，不能当成已验证事实投放到地图上。

原稿档案本身也保留待核说明；这是内容保全，不是历史真实性认证。原有媒体是占位卡，并未绑定可靠档案图片，因此新档案面板省略无图区域。项目现存图片及引用文献没有删除，未扩充网络图片或历史事实。

地理文件、版本、来源及覆盖限制见 [地理数据说明](public/geo/README.md)。现代地图位置不代表历史国籍，边界不随时间改变。

## 结构

- `src/state/`：页面状态与 URL 同步。
- `src/globe/`、`src/country/`、`src/geo/`：三维、二维地图与地理处理。
- `src/timeline/`：时间范围与年代显示。
- `src/record/`：档案面板与聚合选择。
- `src/shell/`：索引、介绍、投稿与弹窗焦点管理。
- `src/data/`：档案、原稿保全和地理标注。

尚需人工确认官方投稿邮箱、原有档案史料及图片使用权；真机双指缩放和设备邮件客户端行为需在目标设备上确认。
