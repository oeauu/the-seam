# 06 测试、验收与交付

## 1. 总体验收标准

本轮只有在以下条件同时满足时才视为完成：

- 三维地球可正常加载、旋转和缩放
- 地区聚类与筛选结果一致
- 点击地区可进入区域档案展台
- 区域条目卡可按地点呈现
- 时间范围筛选可用
- 来源和文化意义筛选可用
- 点击条目可聚焦并打开详情
- 返回后恢复区域或全球视角
- 二维地图仍可使用
- WebGL 不可用时自动回退
- 构建、lint、单元测试和端到端测试通过
- README 和执行报告完成

## 2. 功能验收用例

### 2.1 全球地球

- 首次进入地图页显示加载状态
- 加载完成后出现地球
- 鼠标拖动可旋转
- 滚轮可缩放
- 触控设备可旋转和缩放
- 地区聚类显示数字
- 聚类数字随筛选改变
- 点击空白区域不会报错

### 2.2 地区进入

- 点击至少三个不同地区可进入区域模式
- 进入动画期间重复点击不会产生状态错乱
- 区域地图边界正常
- 卡片出现在合理地点
- 没有坐标的条目不会导致场景错误
- 返回全球后地球可继续操作

### 2.3 卡片与详情

- 图像卡可加载缩略图
- 图片错误时显示占位卡
- 无图条目显示档案模板
- 同地点多条记录显示聚类或列表
- 点击卡片后相机聚焦
- 详情显示正确条目
- 关闭详情后相机恢复
- ESC 可关闭
- 浏览器返回键可关闭或返回上一层

### 2.4 时间范围

- 可输入公元前年份
- 可输入公元年份
- 无公元 0 年
- 起始年份不能晚于结束年份
- 条目时间范围相交时显示
- 时间不详条目受开关控制
- 快速拖动不会产生白屏

### 2.5 来源与文化意义

- 可选择一个来源
- 可多选来源
- 可清空来源
- 可选择文化意义
- 三维和二维结果一致
- 选中状态在切换视图后保留

### 2.6 回退模式

- 手动切换二维有效
- 减少动态效果环境可进入二维或低动态三维
- 模拟 WebGL 失败时显示二维地图
- 二维模式可打开详情
- 二维模式可使用同一时间范围和筛选

## 3. 单元测试最低范围

至少覆盖：

- `formatHistoricalYear`
- `historicalYearToAxis`
- `axisToHistoricalYear`
- `rangesOverlap`
- 时间不详处理
- `latLngToVector3`
- 区域投影坐标转换
- 地区聚类
- 地点聚类
- 来源筛选
- 文化意义筛选
- 条目主媒体选择
- 条目主地点选择
- 导航状态转换
- 返回相机姿态恢复逻辑

## 4. 组件测试最低范围

- AtlasViewport 自动选择三维或二维
- 时间输入校验
- 时间预设
- 来源筛选
- 聚类列表
- 详情覆盖层打开关闭
- 无图占位卡
- 图片错误回退

Three.js Canvas 可使用测试替身，不要求在单元测试环境真实渲染 WebGL。

## 5. 端到端测试最低范围

Playwright 至少包含以下桌面流程：

```text
进入地图页
等待地球加载
点击一个地区聚类
进入区域展台
点击一个档案卡
打开详情
关闭详情
返回全球
切换二维模式
确认二维地图存在
```

再包含一个筛选流程：

```text
设置时间范围
选择来源
确认结果数量变化
切换三维和二维
确认结果数量一致
```

如果 CI 环境不能稳定运行真实 WebGL，允许端到端测试通过浏览器启动参数使用软件渲染，或以二维回退流程作为 CI 稳定用例。必须在执行报告中说明。

## 6. 质量门槛

### 6.1 TypeScript

- 不新增 `any`
- 不新增 `as any`
- 不新增 `@ts-ignore`
- 不用非空断言掩盖不确定数据
- 外部 GeoJSON 数据需要类型守卫或受控边界

### 6.2 组件规模

- 新增核心组件建议不超过 300 行
- 超过 400 行必须拆分或在执行报告说明
- `App.tsx` 应明显减负
- 三维和二维逻辑不得放在同一个巨型文件

### 6.3 性能

不设脱离设备环境的绝对 FPS 承诺，但需要满足：

- 普通桌面浏览器中旋转和缩放无持续明显卡顿
- 时间筛选不会整页冻结
- 非地图页面不加载三维主包
- 纹理按需加载
- 离开区域后不保留无限纹理
- 性能下降时可降低质量或回退二维

执行报告应记录至少一次桌面手工性能检查结果。

### 6.4 可访问性

- Canvas 有替代描述
- 三维对象存在同步可访问列表
- 控件可键盘操作
- 详情焦点正确管理
- 不依靠颜色单独传递信息
- 减少动态效果生效

## 7. 视觉验收

通过条件：

- 整体呈现像数字博物馆或档案馆
- 地球与区域展台清楚、克制
- 文化材料是视觉主体
- 没有大面积彩虹渐变
- 没有金色奢华仿制
- 没有游戏任务点风格
- 没有所有条目统一西式画框
- 卡片根据材料类型有差异
- 文字清晰可读
- 时间轴像展览时间带

不通过条件：

- 仅把二维地图替换成发光球体
- 地球表面直接铺满图片
- 卡片严重遮挡
- 动画过多影响阅读
- 视觉照搬参考视频
- 使用未经许可的艺术品图片

## 8. 内容验收

- 现有迁移内容标记为 demo
- 不新增未经核验的历史事实
- 不修改项目的非身份分类原则
- 不新增男同、女同、跨性别等前台身份筛选
- 文化意义继续作为解释入口
- 所有媒体有 alt
- 媒体权利状态有字段

```bash
npm run lint
npm run test
npm run test:e2e
```

   - 最终 commit SHA
   - 测试结果
