# 02 产品与交互规格

## 1. 产品体验目标

用户进入 The Seam 的地图页时，不应先看到普通列表，也不应看到堆满图片的球体。

主体验应建立三个尺度：

1. 全球尺度
2. 区域尺度
3. 单条档案尺度

三个尺度之间通过连续镜头与状态转换连接。

## 2. 全球尺度

### 2.1 默认画面

- 中央为可旋转的三维地球
- 地球采用低饱和博物馆式地图风格
- 背景保持克制，不使用视频中的金色粒子海
- 地球上显示地区聚类标记
- 聚类标记显示当前筛选条件下的条目数量
- 左上或顶部保留项目标题与主要导航
- 底部常驻时间范围控制器
- 侧边保留来源和文化意义筛选

### 2.2 用户操作

- 拖动旋转地球
- 滚轮或触控缩放
- 点击地区聚类
- 搜索并定位地区或条目
- 调整时间范围
- 调整来源分类
- 调整文化意义标签
- 切换三维与二维模式

### 2.3 全球尺度展示规则

全球尺度不得展示所有具体图片卡片。

优先展示：

- 地区聚类数量
- 少量代表性档案标记
- 当前筛选结果总数
- 鼠标悬停时的地区名称和条目数量

这样可以避免地球表面成为无法阅读的图片墙。

## 3. 区域尺度

### 3.1 进入方式

用户点击地区聚类后：

1. 目标地区高亮
2. 相机平滑靠近
3. 全球地球降低透明度或退出画面
4. 区域地图展台进入
5. 条目卡片从对应地点上方逐步显现

过渡应持续约 600 至 1000 毫秒。具体时长由实际体验调整。

不得使用突然切页。

### 3.2 区域地图展台

区域展台不是传统平面网页地图。

它应表现为：

- 轻微倾斜的地图桌面
- 低高度浮雕或边界线
- 克制的地形与行政轮廓
- 档案卡片位于地点上方
- 卡片具有适度高度差
- 远处卡片尺寸减小
- 卡片始终保持基本可读方向

地图展台可以使用区域 GeoJSON 绘制到 Canvas 纹理，再映射到 Three.js 平面。卡片坐标必须使用同一投影函数。

### 3.3 卡片层级

卡片按距离和密度分为三档：

#### 远距离

- 只显示地点聚类
- 不加载完整图片
- 显示数量和地区名称

#### 中距离

- 显示代表性缩略图或档案封面
- 同地点多条记录仍保持聚类
- 只加载当前可见区域纹理

#### 近距离

- 展开具体档案卡
- 显示标题、时期和来源的最小信息
- 可点击进入聚焦模式

## 4. 单条档案尺度

### 4.1 聚焦动画

点击档案卡后：

1. 记录当前相机位置
2. 其他卡片降低亮度或透明度
3. 相机平滑靠近选中卡片
4. 卡片在画面中央放大
5. 博物馆式详情预览从侧边进入

不得把每个条目套入同一种金色画框。

### 4.2 档案展示模板

根据媒体类型选择不同模板：

- 图像作品卡
- 文献页卡
- 纯文本档案卡
- 口述记录卡
- 法律或医学文书卡
- 无图占位卡

无图条目不得用无关装饰图代替。

### 4.3 详情预览

聚焦状态至少显示：

- 标题
- 原文名
- 时间
- 地点
- 来源类型
- 文化意义
- 证据等级
- 演示数据或审核状态
- 简短说明
- 查看完整档案按钮
- 返回区域按钮

点击“查看完整档案”后复用现有 `DetailsDrawer` 或未来条目详情页。

关闭详情后，相机恢复到进入聚焦前的位置。

## 5. 时间交互

### 5.1 控件形态

底部时间轴采用博物馆展墙时间带风格，支持：

- 双滑块范围
- 起始年份输入
- 结束年份输入
- BCE 与 CE
- 全部时间
- 古代、前现代、近现代、当代等快捷预设
- 时间不详开关

快捷预设只是导航工具，不应替代精确范围。

### 5.2 条目显隐

当条目进入筛选范围时：

- 从地图表面轻微升起
- 透明度从 0 过渡到 1
- 缩放从 0.85 过渡到 1

当条目离开筛选范围时：

- 透明度下降
- 轻微下沉
- 动画结束后卸载或隐藏

不得在每次滑动时立即销毁并重建整个场景。

### 5.3 播放模式

本轮可以保留当前时间自动播放概念，但应变为可选增强。

自动播放应移动时间窗口，不应仅在固定刻度之间跳跃。

如果实施风险过高，可以在本轮保留暂停状态和预设跳转，在执行报告中说明。

## 6. 来源与文化意义筛选

### 6.1 来源分类

来源筛选继续作为主分类，至少支持：

- 历史文献
- 地方志
- 神话与宗教文本
- 文学与戏剧
- 法律与制度档案
- 医学文本
- 民间传说与口述记忆
- 艺术与视觉材料
- 现代研究
- 现代再阐释

实际前端选项应由数据配置生成，不得在多个组件重复硬编码。

### 6.2 文化意义

文化意义不是身份分类。

示例包括：

- 越界
- 变形
- 神圣化
- 污名化
- 守护
- 隐匿
- 召回
- 表演
- 权力亲密
- 地方记忆
- 法律规训
- 现代再激活

筛选器视觉应像馆藏索引，不像社交媒体标签云。

## 7. 多事件与多地点

### 7.1 同地点多条记录

同地点存在多条记录时，默认显示聚类卡。

点击后显示：

- 条目数量
- 时间范围
- 来源分布
- 可展开的条目列表

不得默认只打开第一条记录。

### 7.2 多地点条目

一个条目可以关联多个地点。

地图可显示多个关联标记，但只保留一个主地点。

点击任一关联地点都应进入同一档案详情。

## 8. 导航与返回

必须支持：

- 全球返回按钮
- 区域返回按钮
- 聚焦关闭按钮
- ESC 键返回上一层
- 浏览器后退键
- URL 可分享状态

建议 URL 状态：

```text
#atlas/global
#atlas/region/east-asia
#atlas/entry/entry_tuer_shen
```

如果继续使用 hash 路由，应集中管理，不得让多个 useEffect 互相覆盖。

## 9. 二维回退

以下情况使用二维地图：

- WebGL 初始化失败
- 用户主动选择二维
- `prefers-reduced-motion: reduce`
- 设备性能监测持续低于阈值
- 屏幕过小且三维交互不可用

二维回退应保留相同筛选数据和条目详情，不是一个内容残缺的备用页面。

## 10. 移动端

移动端第一版不追求与桌面完全一致。

建议：

- 全球地球可单指旋转、双指缩放
- 区域展台减少卡片数量
- 详情使用底部抽屉
- 时间轴可横向滚动或展开为全屏控制器
- 默认降低像素比与纹理数量
- 极低性能设备直接使用二维地图

## 11. 无障碍

- 所有地图操作提供键盘替代入口
- 所有聚类和档案卡有可访问名称
- 三维 Canvas 外提供同步的隐藏或可见列表
- 详情可通过键盘打开和关闭
- 焦点进入详情后被正确管理
- 关闭详情后焦点返回触发对象
- 不仅依靠颜色表达证据等级和状态
- 尊重减少动态效果

## 12. 未来预留

本轮不实现，但架构应允许：

- 地图模式与三维编年长廊模式切换
- 自动策展导览
- 区域专题展览
- 多语言条目版本
- 正式后端数据源
- 贡献者和审核员权限
