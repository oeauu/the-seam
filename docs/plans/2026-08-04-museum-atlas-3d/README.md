# The Seam 三维博物馆时空地图计划

本目录是 Codex 执行本轮三维时空体验升级的唯一计划入口。

本轮目标不是重写整个 The Seam，也不是把参考视频的金色视觉照搬进项目。目标是在保留现有 React + TypeScript + Vite 项目、档案浏览、投稿原型、双语能力和博物馆式理性审美的前提下，将当前二维 D3 地图升级为具有以下能力的三维时空档案入口：

1. 全球尺度的可旋转三维地球
2. 全球地球向区域档案展台的连续镜头过渡
3. 区域地图上按地点分布的档案卡片
4. 时间范围、来源和文化意义的联动筛选
5. 点击档案卡后平滑聚焦，并进入博物馆式详情展示
6. WebGL 不可用、低性能设备和减少动态效果环境下的二维回退

## 本轮范围

本轮需要完成一个可运行、可构建、可测试的三维博物馆时空地图 MVP，并与现有档案详情和筛选功能贯通。

本轮不接入正式 Supabase 后端，不实现真实账号鉴权，不建立生产级投稿数据库，不批量扩充历史条目，不将未经核验的演示数据视为正式史料，不实现完整的三维编年长廊模式。

## 参考效果的取舍

参考视频提供以下可借鉴内容：

- 大量文化对象在空间中的层级组织
- 地图、时间和展品之间的联动
- 点击对象后的镜头推进
- 远景聚合、中景缩略图、近景单件展品的尺度变化
- 地图模式与编年观看之间的潜在转换

The Seam 不采用视频中的金色奢华、戏剧化画框、霓虹粒子和密集堆叠作为最终视觉。项目继续采用博物馆式、严谨、理性、克制的数字档案美学。文化材料本身构成主要视觉内容。

## 执行纪律

- 不使用 `any`、`as any`、`@ts-ignore` 掩盖类型问题
- 不在单个巨型组件中继续堆积逻辑
- 不删除现有二维地图，二维地图必须成为回退模式
- 不添加未经许可或来源不明的图片
- 不把演示数据包装成已经核验的历史事实
- 不直接提交到 `main`，Codex 应在功能分支完成并提交
- 每个阶段完成后运行相应检查并记录结果
- 最终新增 `EXECUTION_REPORT.md`，说明完成内容、测试结果、已知限制和后续建议
