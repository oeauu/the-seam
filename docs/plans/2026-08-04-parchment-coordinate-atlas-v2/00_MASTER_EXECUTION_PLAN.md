# 00 总执行计划

## 一、项目背景

当前 `feat/museum-atlas-3d` 已完成三维地图技术原型，建立了 `ArchiveEntry` 数据模型、时间范围筛选、来源与文化意义筛选、全球地球、地区场景、详情整合和测试基础。

现有版本仍属于工程原型。全球视图使用抽象球体，地区视图使用矩形平面，条目以悬浮档案卡片呈现，真实地理轮廓、名称标签管理、三维羊皮纸材质和连贯的时间交互尚未建立。

本轮不继续完善悬浮展品。新的目标是建立一种更接近博物馆历史地图室的三维观看秩序：陈旧羊皮纸成为三维地球与三维区域地图的材质，条目以金色坐标点贴附在真实地点，名称附着于坐标附近，文化材料只在用户主动调阅时进入详情面板，时间轴则成为羊皮卷下端的一部分。

三维是本轮的默认体验、主要体验和主要验收对象。羊皮纸通过三维曲率、细微表面起伏、光照变化、镜头移动和材质响应获得流动感与质感。二维只保留为 WebGL 真正不可用或用户主动选择时的兼容路径。

核心原则为：

> 地图负责定位，坐标负责索引，名称负责识别，时间卷轴负责历史移动，详情面板负责展示文化材料。

## 二、最终体验目标

### 1. 全球视图

用户进入 Atlas 后看到一个可旋转的三维地球。地球呈现为数字化历史地图仪，表面使用低对比度羊皮纸材质。纸张纤维、氧化色差、地球曲率和光照共同构成质感。国家边界和海岸线清晰但克制。

条目在球面上显示为贴附地表的暗金或旧铜坐标点。远景不显示全部名称，而使用地区聚类和少量代表标签。坐标不得明显悬浮于地表，不使用霓虹光柱、跳动粒子或游戏任务标记。

### 2. 地区视图

用户点击地区聚类后，镜头连续靠近目标区域。全球地球通过相机推进、局部放大和场景交叉淡化进入地区视图。

地区地图必须来自可追溯的 GeoJSON 或 TopoJSON，不再使用矩形展台。地图保持三维存在，可以通过轻微厚度、压纹边界、纸张波纹、局部起伏和光照变化产生空间感，但不得做成夸张地形模型。

条目坐标按照与地区轮廓完全一致的投影落在地点上。

### 3. 坐标与名称

每个条目使用金色坐标点表示，坐标附近显示条目名称。

名称标签根据缩放层级、屏幕空间、重要程度和遮挡情况动态管理：

- 远景显示聚类数量和地区名称
- 中景显示代表条目名称
- 近景显示当前区域内尽可能多的可读名称
- 悬停标签获得优先权
- 选中标签始终显示
- 被遮挡或在地球背面的标签不显示
- 同一地点多条目使用一个坐标和数量提示，点击后展开条目列表

### 4. 羊皮卷时间轴

时间轴位于羊皮卷下端，视觉上属于地图本体，而不是外置表单。

用户拖动起止年份时，需要产生克制而清晰的滑动感：

- 下端卷轴、刻度带或纸边产生轻微横向位移和回弹
- 当前年份刻度保持清晰，远离当前范围的刻度逐渐降低对比度
- 坐标根据时间范围平滑显隐、重新聚合或解除聚合
- 标签与坐标同步，不允许出现坐标已隐藏但名称仍残留
- 地图产生极轻微的光泽或纸张张力变化，提示历史范围正在移动
- 拖动过程中使用即时预览，释放后再执行精确聚类和 URL 状态提交
- 不使用剧烈卷纸、翻页、燃烧、碎裂或高速穿越动画

时间轴需要支持双滑块、手动年份输入、BCE/CE 格式、时间不详开关、历史时期预设和键盘操作。

### 5. 档案调阅

点击坐标后，地图保持在背景中，右侧打开博物馆式档案面板。面板展示标题、原文名、时间、地点、来源、证据等级、解释风险、摘要和相关媒体。

点击坐标时可以进行轻微的镜头靠近、重新居中或局部光照强调，但不把展品从地图上抬升，也不把整张卡片悬浮在场景中央。

关闭详情后应恢复选中前的三维相机姿态和时间范围。

### 6. 视觉动态语言

本项目不完全复制参考视频，但需要吸收其中“空间、时间、对象与镜头相互联动”的优点。

允许使用：

- 地球缓慢惯性旋转
- 全球到地区的连续镜头推进
- 羊皮纸材质随视角产生细微高光变化
- 坐标进入时间范围时的透明度与尺度过渡
- 标签由聚类向具体名称的渐进展开
- 选中坐标的低幅度呼吸光或金属高光
- 时间轴拖动时的纸张张力、刻度滑动和轻微回弹
- 详情打开时地图轻微退暗和局部居中

禁止使用：

- 霓虹粒子、光柱、爆炸、飞散碎片
- 夸张的纸张卷曲和影视道具式翻页
- 大幅自动旋转导致眩晕
- 坐标从地面升起成为悬浮展品
- 为追求动画牺牲地点准确性和阅读稳定性

### 7. 动态效果与兼容

`prefers-reduced-motion` 不自动切换二维。低动态三维模式应：

- 关闭自动旋转
- 降低 OrbitControls 惯性
- 缩短或取消跨场景补间
- 关闭非必要材质流动和光照漂移
- 取消时间轴回弹，仅保留位置同步
- 保留旋转、缩放、坐标点击和详情调阅

只有 WebGL 无法创建、Canvas 持续报错、明确的性能降级策略触发或用户显式选择二维时，才进入二维兼容模式。

二维模式只需保证位置、筛选、名称、时间范围和详情功能完整，不要求复刻三维羊皮纸的全部材质和空间效果。

## 三、MotionSites 使用原则

MotionSites 可以作为现成动效结构、section 组织和提示词参考库使用，但不得被视为地图运行时框架。

允许借鉴：

- 时间轴拖动、回弹和刻度滑动节奏
- 面板进入与退出
- 标题与标签的层级展开
- 详情抽屉、筛选栏和响应式导航的 motion pattern
- 低动态模式与移动端简化策略

不得直接套用：

- 与本项目审美冲突的黑色赛博、玻璃拟态、霓虹或营销落地页模板
- 会覆盖 Three.js 主场景的整页滚动叙事
- 未取得使用权的 premium prompt、视频背景、字体、图片和代码
- 为了匹配模板而引入 Tailwind、Framer Motion 或其他依赖

如果用户已经拥有并提供某个 MotionSites prompt，可把它作为实现参考附入执行记录。Codex 必须提取其中可复用的运动参数和组件结构，再改写为本项目的设计语言，不得整段复制未知许可内容。

Framer Motion 仅在 DOM 层确有明显收益时引入。Three.js 相机、材质、坐标和球体动画继续由 React Three Fiber 与 `useFrame` 控制。

## 六、关键技术决策

### 1. 羊皮纸材质

优先使用程序生成的 CanvasTexture、DataTexture 或本地可追溯纹理。程序纹理应包含低频色差、细微纤维、轻微斑驳和边缘变化，但不得出现烧焦边缘、夸张裂纹、大片污渍或影视道具式仿旧。

纹理必须可复现，随机噪声使用固定 seed。材质可结合 roughness、normal 或极轻微 displacement，但不能造成地理位置变形。

### 2. 全球边界

从现有世界 TopoJSON 或本地 GeoJSON 生成海岸线和国家边界。边界可以使用 Three.js LineSegments、Line2 或预渲染纹理。必须控制线条密度和分辨率，避免移动端负担过重。

### 3. 地区投影

地区视图使用统一的投影工厂。地理轮廓和条目坐标共享同一个 projection 实例及其 extent。

不得继续采用“当前条目经纬度最小最大值归一化”作为正式地区地图。不得用一套坐标绘制点，用另一套坐标控制相机。

### 4. 坐标点

小规模可以使用单独 mesh，中长期提供 InstancedMesh 路径。坐标点由中心点、细环或短针脚构成，视觉上贴附地图。

球面坐标只允许使用极小的法线偏移避免 z-fighting。该偏移不能造成肉眼可见的悬浮。

### 5. 标签层

名称标签使用屏幕空间 DOM 层或高效的文本层，不再为每条记录创建完整 Three.js `Html` 卡片。标签位置由三维点投影到屏幕坐标得到，布局在独立层完成。

标签层必须支持地球背面剔除、屏幕边界剔除、碰撞检测、优先级排序、缩放层级、悬停与选中置顶、双语长度变化和移动端标签预算。

### 6. 时间轴状态

拖动时更新 `previewRange`，以节流方式预览坐标透明度和标签变化。释放、键盘确认或输入框失焦后更新 `committedRange`，再执行精确筛选、聚类、hash 和统计更新。

时间轴动画应优先使用 CSS transform、requestAnimationFrame 或轻量 spring。不得在每个 pointermove 中重建 Three.js geometry、纹理或完整聚类树。

### 7. 详情展示

详情面板由 React DOM 渲染，不放入 WebGL 场景。地图只负责记录当前选中坐标、相机姿态和场景状态。

Codex 必须严格按 `05_IMPLEMENTATION_PHASES.md` 执行。总体顺序为：

1. 建立基线和新分支

5. 重构真实三维地区地图

7. 建立名称标签和避让系统

10. 整合详情、时间和筛选
11. 调整低动态三维、性能与移动端
12. 保留最低限度二维兼容
13. 测试、截图、文档和执行报告

## 八、停止条件

出现以下任一情况时不得继续叠加功能：

- build 失败
- TypeScript 错误
- 地区轮廓与坐标使用不同投影
- 坐标明显偏离真实地点
- 标签大面积重叠或在地球背面穿透显示
- 时间轴拖动导致场景持续重建或明显卡顿
- 坐标已隐藏但标签仍残留
- 详情 hash 失效
- 旧地图或档案页面无法访问
- WebGL 失败时无法进入兼容模式
- 外部纹理、字体或 MotionSites 资源成为运行必需项

必须先修复当前阶段，再进入下一阶段。
