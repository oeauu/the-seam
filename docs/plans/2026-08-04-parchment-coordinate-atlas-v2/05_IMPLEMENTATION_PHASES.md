# 05 实施阶段

## 总体原则

每一阶段结束时仓库必须保持可构建。Codex 可以并行分析，但核心场景、状态和样式的代码集成必须由单一主上下文完成。

## Phase 0：基线与新分支

### 操作

1. 拉取远端 `feat/museum-atlas-3d`
2. 确认 HEAD 包含 V1 执行报告和代码
3. 运行安装、build、lint、unit、e2e
4. 记录现有警告、audit、bundle 和截图
5. 创建 `feat/parchment-coordinate-atlas-v2`
6. 新建本计划目录中的 `EXECUTION_REPORT.md`

### 验收

- 基线可复现
- 新分支来源正确
- V1 功能未被误认为 main 内容

## Phase 1：统一坐标与地点分组

### 操作

1. 新增 `LocationGroup` 类型
2. 建立地点分组选择器
3. 编写精度感知的坐标容差
4. 建立统一地区投影上下文
5. 让地区边界、坐标和相机目标共用投影
6. 删除 `longitude / 30` 等临时聚焦计算
7. 补充三个以上地区的投影 fixtures

### 必测

- 同 location ID 分组
- 相邻但不同地点不误合并
- 多条目地点数量正确
- 经纬度到地区坐标映射
- 相机目标与 marker 位置一致

### 验收

- 坐标体系只有一个来源
- 不存在明显偏点
- build、lint、unit 通过

## Phase 2：三维羊皮纸材质系统

### 操作

1. 建立 Atlas 视觉令牌
2. 使用固定 seed 生成羊皮纸 base、roughness 和可选 normal
3. 建立 high、medium、low 三种质量
4. 加入资源释放和缓存
5. 创建最小材质预览场景或 Story fixture
6. 记录纹理生成参数

### 验收

- 纹理每次运行一致
- 不依赖外部 CDN
- 羊皮纸不呈塑料、金属或烧焦道具感
- 低质量模式显著减轻 GPU 开销

## Phase 3：全球三维羊皮纸地球

### 操作

1. 重构 `GlobeScene`
2. 使用羊皮纸材质替换纯色球体
3. 加入本地世界边界数据
4. 绘制海岸线和国家边界
5. 建立贴附球面的地区聚类
6. 添加代表标签和背面剔除
7. 调整光照、背景和相机
8. 保留旋转、缩放和阻尼

### 验收

- 地球具有纸张材质和曲率质感
- 海岸线可辨认
- 坐标贴附球面
- 背面标签不穿透
- 旋转时标签稳定
- 支持低动态三维

## Phase 4：真实三维地区地图

### 操作

1. 准备至少三个可追溯地区几何数据
2. 使用统一投影生成真实轮廓
3. 创建轻微厚度或压纹的羊皮纸表面
4. 绘制内部边界和主要地理线
5. 建立全球到地区过渡
6. 建立地区到全球返回
7. 保存和恢复相机姿态
8. 移除矩形展台正式路径

### 验收

- 至少三个地区轮廓真实
- 地区地图保持三维质感
- 坐标与轮廓一致
- 进入和返回不跳闪
- 没有矩形板冒充地区

## Phase 5：金色坐标系统

### 操作

1. 新增 `CoordinateMarker3D`
2. 新增 location group marker layer
3. 设计默认、悬停、选中和聚类状态
4. 坐标贴附球面或地区表面
5. 加入可点击 hit area
6. 规模达到阈值时使用 InstancedMesh
7. 停止渲染 `ArchiveCard3D`
8. 清理无用 HTML 卡片样式

### 验收

- 地图上不存在悬浮档案卡片
- 坐标清楚但克制
- 同地点只显示一个坐标
- 选中状态不会改变地理位置
- 键盘替代入口可用

## Phase 6：名称标签与避让

### 操作

1. 建立 label candidates 选择器
2. 三维坐标投影到屏幕空间
3. 实现背面和视锥剔除
4. 实现碰撞检测与候选位置
5. 建立远、中、近景预算
6. 选中与悬停标签置顶
7. 处理双语长度
8. 处理移动端预算
9. 相机运动时简化布局，停止后精确布局

### 验收

- 无大面积标签重叠
- 背面标签不可见
- 选中标签稳定
- 坐标隐藏时标签同步隐藏
- 中英文切换不导致失控

## Phase 7：羊皮卷下端时间轴

### 操作

1. 将现有 AtlasTimeline 重构为 `ParchmentTimeline`
2. 时间轴嵌入地图下端视觉
3. 建立 `previewRange` 与 `committedRange`
4. 使用 rAF 合并 pointer 更新
5. 建立双把手、手动输入、预设和时间不详
6. 加入刻度带横向滑动
7. 加入低幅度纸张张力和释放回弹
8. 坐标、标签和聚类联动
9. 更新 aria-valuetext 和键盘操作
10. 低动态模式取消回弹

### 验收

- 拖动有清楚滑动感
- 不卡顿、不重建 geometry
- 释放后范围准确
- 无公元 0 年
- 坐标与标签同步
- 时间轴属于地图整体而非外置表单

## Phase 8：同地点多条目与详情

### 操作

1. 新增 `LocationEntryPopover`
2. 单条目直接打开详情
3. 多条目先显示列表
4. 复用 canonical `DetailsDrawer`
5. 保存相机姿态和时间范围
6. 地图轻微退暗并居中
7. 关闭后恢复状态
8. 完善 hash 和浏览器返回
9. Escape 逐层返回

### 验收

- 同地点条目均可访问
- 详情不悬浮在 WebGL 内
- 返回恢复原视角
- 分享链接有效
- 当前条目被筛掉时有明确处理

## Phase 9：MotionSites 动效模式提取

### 操作

1. 查看用户已合法获得并提供的 MotionSites prompt 或公开 section
2. 只提取可复用的 motion pattern
3. 记录来源名称、用途和改写方式
4. 优先用于时间轴、详情面板、筛选栏和响应式交互
5. 根据现有 CSS 或轻量动画实现
6. 只有确有收益时才引入 Framer Motion

### 验收

- 没有整站照搬
- 没有 premium 内容未经授权进入仓库
- 动效符合博物馆审美
- 依赖变更有说明

如果用户没有提供具体 premium prompt，本阶段仅使用公开可见的结构概念，不得猜测受限内容。

## Phase 10：性能、移动端与低动态三维

### 操作

1. 建立分级质量策略
2. 自适应 DPR
3. 简化边界几何
4. 限制标签预算
5. 关闭低质量 normal/displacement
6. 调整 PerformanceMonitor 降级路径
7. `prefers-reduced-motion` 保留三维
8. 移动端底部详情抽屉
9. 处理触控冲突
10. 检查纹理和 geometry 释放

### 验收

- 低动态环境仍为三维
- 普通桌面操作流畅
- 移动端可拖动时间轴
- 反复进入地区无持续内存增长
- 持续低性能时才提示二维

## Phase 11：最低限度二维兼容

### 操作

1. 保留 WebGL 失败入口
2. 共享筛选、地点分组和详情
3. 维持可读的平面坐标和标签
4. 不投入与三维同等的材质开发
5. 确保用户可以手动切换和返回三维

### 验收

- WebGL 失败时功能可用
- 二维不阻碍三维开发
- 数据结果与三维一致

## Phase 12：测试、截图与交付

### 操作

1. 补齐选择器与投影单元测试
2. 补齐时间轴组件测试
3. 补齐标签布局测试
4. 增加三维 smoke test
5. 增加低动态三维 E2E
6. 增加同地点多条目 E2E
7. 运行 build、lint、unit、e2e
8. 检查 bundle 和 npm audit
9. 保存指定截图
10. 更新 README 和执行报告
11. 推送新分支

### 必须截图

- 全球三维羊皮纸地球
- 一个地区真实轮廓
- 金色坐标和名称标签
- 时间轴拖动中与释放后
- 同地点多条目列表
- 详情面板
- 低动态三维
- 二维兼容

## 阶段间停止条件

出现以下情况时立即停止继续叠加：

- build 或 TypeScript 失败
- 地区坐标与轮廓错位
- 标签穿透地球背面
- 时间拖动导致明显冻结
- MotionSites 模板改变项目核心审美
- 三维被错误替换成平面主体验
- 详情或分享链接失效

先修复当前阶段，再进入下一阶段。
