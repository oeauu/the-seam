# 06 测试、验收与交付标准

## 一、测试命令

最终至少运行：

```bash
npm run build
npm run lint
npm run test
npm run test:e2e
```

如果新增视觉回归或截图脚本，需要记录命令和产物路径。

## 二、单元测试

### 地点分组

- 相同 location ID 合并
- 不同城市不误合并
- 坐标容差按精度变化
- 无坐标条目不伪造坐标
- 多条目地点数量正确

### 地区投影

- 地区 bounds 有效
- 轮廓和点位共用 projection
- 已知城市落入合理区域
- 相机目标等于 marker scene position
- 窗口尺寸变化后投影可重算

### 时间

- BCE/CE 格式正确
- 无公元 0 年
- preview 与 committed 状态转换正确
- 时间范围相交正确
- 时间不详开关正确
- 拖动顺序反转时自动归一化

### 标签布局

- 背面点被剔除
- 屏幕外点被剔除
- 高优先级标签保留
- 碰撞时低优先级标签隐藏或换位
- 选中标签始终显示
- 中英文标签均可布局

### 性能降级

- full 与 reduced motion profile 正确
- reduced motion 不切换二维
- quality level 按顺序降级
- WebGL 失败才进入二维兼容

## 三、组件测试

### ParchmentTimeline

- 双把手可拖动
- pointermove 更新 preview
- pointerup 提交 committed
- 输入框处理 BCE 和无效值
- 预设按钮有效
- 低动态模式无回弹
- aria-valuetext 正确

### LocationEntryPopover

- 单地点多条目完整列出
- 键盘可选择
- Escape 返回
- 选择条目后打开详情

### AtlasLabelLayer

- 选中、悬停和普通状态正确
- 坐标被筛除时标签消失
- resize 后位置更新

## 四、E2E 主路径

### 1. 三维全球路径

- 打开 Atlas
- 默认进入三维
- 羊皮纸地球可见
- 聚类和代表标签存在
- 旋转或缩放不会报错

### 2. 全球到地区

- 点击聚类
- 进入真实轮廓地区
- 坐标落在地区范围内
- 返回全球有效

### 3. 时间卷轴

- 拖动起始或结束把手
- 坐标数量预览变化
- 释放后统计和 URL 更新
- 坐标与标签一致

### 4. 同地点多条目

- 点击带数量的坐标
- 条目列表出现
- 可打开第二条而非仅第一条
- 关闭后回到原地点

### 5. 详情与 hash

- 点击坐标打开详情
- hash 可复制
- 刷新后恢复条目
- 浏览器返回逐层恢复

### 6. 低动态三维

- 模拟 `prefers-reduced-motion`
- 仍加载三维
- 无自动旋转和回弹
- 坐标、时间轴和详情可用

### 7. WebGL 失败

- 模拟 WebGL unavailable
- 进入二维兼容
- 筛选、时间和详情仍可用

## 五、人工视觉验收

自动测试不能替代以下人工检查：

### 全球地球

- 羊皮纸有纤维和氧化层次
- 地球仍具有曲率、光照和流动感
- 不像塑料球、木球或奇幻游戏道具
- 边界不抢坐标

### 地区地图

- 真实轮廓可辨认
- 有轻微三维厚度或压纹
- 无矩形展台残留
- 坐标与地名位置可信

### 坐标和标签

- 金色克制
- 不形成霓虹点阵
- 标签可读
- 背面不穿透
- 近景不大面积重叠

### 时间卷轴

- 位于羊皮卷下端
- 拖动有滑动感和轻微张力
- 不像系统默认 range
- 不像游戏进度条
- 拖动不造成视觉眩晕

### 详情面板

- 像博物馆调阅卡
- 地图仍可感知
- 进入退出节奏自然
- 没有套用不合适的营销模板

## 六、性能验收

至少记录：

- 桌面浏览器与 GPU
- 移动设备或移动模拟
- 初次进入 Atlas 的加载时间
- Atlas 3D chunk 大小
- 羊皮纸纹理大小
- 世界边界数据大小
- 全球场景平均帧率或主观流畅度
- 地区场景平均帧率或主观流畅度
- 时间轴拖动时是否掉帧
- 反复进入三个地区后的内存变化

不得只写“性能良好”。没有实测的数据必须标记为未测。

## 七、验收等级

### 完成

功能、视觉、测试与截图均满足要求。

### 原型完成

技术路径存在，但视觉、精度或交互仍未达到正式标准。执行报告必须这样写，不得写成完整完成。

### 未完成

只有占位组件、假数据路径或未接通状态。

Codex 必须逐阶段使用以上等级，禁止把所有 Phase 机械标记为已完成。
