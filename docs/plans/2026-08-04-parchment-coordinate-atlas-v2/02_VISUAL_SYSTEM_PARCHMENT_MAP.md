# 02 三维羊皮纸视觉系统

## 一、视觉定位

The Queer Archive 的 Atlas 应呈现为一件数字博物馆中的历史地图仪，而不是复古游戏地图、奇幻卷轴、航海冒险界面或当代营销网站。

文化内容本身构成美学。界面的任务是提供严谨、克制、可读且有材料感的展示空间。

关键词：

- 数字博物馆
- 历史地图室
- 馆藏目录
- 羊皮纸纤维
- 墨色边界
- 旧铜坐标
- 低饱和光照
- 精密刻度
- 空间连续性

## 二、三维羊皮纸材质

### 1. 基础色

建议建立 Atlas 专用设计令牌：

- parchment-base: `#c8ad78`
- parchment-light: `#d9c494`
- parchment-shadow: `#8f7449`
- parchment-fiber: `#6f5a38`
- ink-primary: `#29231b`
- ink-secondary: `#5f5037`
- coordinate-gold: `#a77a28`
- coordinate-highlight: `#d0aa55`
- oxidized-bronze: `#78613a`
- panel-paper: `#d4c197`

Codex 可以根据实际渲染调整，但不得变成高饱和橙黄或纯金奢华风。

### 2. 纹理结构

羊皮纸纹理至少包含：

- 低频色差
- 细微纸张纤维
- 极轻的斑驳
- 不均匀 roughness
- 极轻的 normal 或 displacement
- 固定 seed，保证每次渲染一致

不得包含：

- 烧焦边缘
- 大片墨渍或血迹
- 夸张裂纹
- 卷角贴图
- 影视道具式破损
- 会遮挡地图线条的强噪声

### 3. 三维响应

地球转动或地区地图改变观察角度时，材质应产生非常轻微的光泽变化。纸张仍应保持哑光，避免塑料感、金属感和湿润感。

建议 roughness 维持较高范围。normal 与 displacement 强度必须极低，只用于捕捉光线，不得改变坐标准确性。

## 三、全球地球

### 1. 地表

地球使用羊皮纸材质。海洋与陆地不必采用现代地图蓝绿配色，可通过浅深墨色、纹理密度或低对比度填充区分。

### 2. 边界

海岸线优先级高于国家边界。国家边界使用更细、更低对比度的墨线。

边界不得发光，不使用霓虹描边。线条需要随缩放保持清楚但不抢夺坐标点。

### 3. 背景空间

场景背景使用深暖灰、墨黑棕或低对比度博物馆展厅色。不得使用星空、宇宙粒子或蓝紫赛博背景。

可以加入非常轻的环境暗角和展柜式聚光，但不做戏剧舞台光。

## 四、地区地图

地区地图是具有真实轮廓的三维羊皮纸片或压纹地图表面。

允许：

- 极轻厚度
- 边界压纹
- 轻微纸面波纹
- 局部高低差
- 细微投影阴影
- 真实轮廓外沿

不允许：

- 矩形底板冒充地区
- 大幅卷曲导致地图坐标失真
- 立体山脉和建筑模型抢夺注意力
- 夸张悬浮离开场景底面

## 五、金色坐标

坐标应像旧铜地图钉、馆藏索引点或金属墨标记。

### 默认状态

- 暗金中心点
- 细环或极短针脚
- 与地图几乎贴合
- 无强光晕
- 保持最小可点击面积

### 悬停状态

- 亮度轻微提高
- 环形描边扩大少量
- 标签置顶
- 可使用一次短促的金属高光扫过

### 选中状态

- 低幅度呼吸光
- 邻近非相关坐标降低对比度
- 坐标保持原位
- 不升起、不弹跳、不形成光柱

### 聚类状态

- 使用一个较大的暗金环
- 中心显示数量
- 附近显示地区或代表名称
- 点击后通过缩放或地区进入解除聚类

## 六、名称标签

标签应接近博物馆地图标注，而非互联网气泡或游戏 tooltip。

视觉要求：

- 字色以深墨或暖象牙为主，取决于背景区域
- 选中标签可使用暗金细线连接坐标
- 不使用高饱和背景色块
- 不为所有标签添加完整卡片边框
- 标签可带极轻半透明纸色底，以保证复杂纹理上的可读性
- 中英文长度变化时保持稳定布局

## 七、羊皮卷下端时间轴

时间轴与地图视觉连续。它可以表现为羊皮纸下端的加厚边、卷轴杆、刻度带或压印年代标尺。

### 必须呈现

- 清楚的起止年份
- 双滑块或双把手
- 刻度和时代预设
- 当前范围的压印或墨色强调
- 拖动时的横向滑动感
- 释放后的轻微回弹

### 不得呈现

- 现代系统默认 range 样式
- 游戏血条式进度条
- 金色奢华装饰
- 夸张卷纸动画
- 不能读清的装饰字体

## 八、详情面板

详情面板像博物馆调阅卡或数字展签，使用纸本浅色或深墨展柜两种方案之一。面板的运动可以参考成熟网站 section 的入场节奏，但视觉必须改写为本项目语言。

打开时：

- 地图轻微退暗
- 面板从右侧平稳进入
- 选中坐标保持高亮
- 不遮住整个地图

关闭时：

- 面板退出
- 地图亮度恢复
- 相机回到原姿态

## 九、MotionSites 参考边界

MotionSites 可作为动效节奏和组件结构参考。优先参考其中的：

- slider 与 carousel 的惯性和释放节奏
- sticky panel 或 drawer 的进入退出
- editorial typography 的层级展开
- hover focus 的轻量状态变化
- responsive menu 和移动端抽屉

不得照搬其中的赛博、玻璃拟态、视频背景、霓虹光效和营销落地页结构。任何 premium 资源只有在用户已合法获得并提供时才可使用。
