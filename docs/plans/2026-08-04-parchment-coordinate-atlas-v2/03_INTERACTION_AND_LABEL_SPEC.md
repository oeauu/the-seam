# 03 交互与标签规范

## 一、交互主线

用户浏览路径为：

1. 进入三维羊皮纸地球
2. 旋转或缩放地球
3. 观察地区聚类和代表名称
4. 点击地区进入真实轮廓的三维地区地图
5. 查看金色坐标与名称标签
6. 拖动羊皮卷下端时间轴
7. 通过来源和文化意义筛选坐标
8. 点击坐标调阅一个或多个档案
9. 关闭详情并返回原三维视角

## 二、全球到地区

点击地区聚类后：

- 锁定重复点击
- 保存全球相机姿态
- 相机平滑靠近目标地区
- 地球边界与坐标逐渐降低对比度
- 地区地图淡入或由局部展开
- 时间轴保持不动，避免用户失去时间上下文
- 动画完成后进入 `region` 状态

过渡建议 600–1100 ms。低动态模式直接切换或缩短到 100–200 ms。

## 三、地区地图操作

地区视图允许：

- 平移
- 缩放
- 小幅倾斜
- 返回全球
- 点击坐标
- 悬停名称

地区地图不允许无限旋转到背面，也不允许用户把地图翻转到不可读方向。

## 四、坐标点击

### 单条目地点

点击后：

- 记录相机姿态
- 坐标进入选中状态
- 相机轻微居中或靠近
- 右侧详情面板打开
- URL 更新为条目 hash

### 多条目地点

点击后先打开 `LocationEntryPopover` 或紧凑条目列表，显示：

- 地点名称
- 条目数量
- 每条目的名称和时间
- 来源类型
- 进入完整档案的按钮

用户选中具体条目后再打开详情面板。

## 五、标签层级

标签候选需要计算优先级，建议考虑：

- 是否选中
- 是否悬停
- 是否为聚类代表
- 是否有明确媒体
- 是否有精确地点
- 证据等级
- 当前缩放级别
- 与屏幕中心的距离
- 是否与当前筛选直接相关

不得用现代身份类别决定优先级。

## 六、标签碰撞

布局流程建议：

1. 将三维坐标投影到屏幕空间
2. 剔除地球背面与视锥外点
3. 按优先级排序
4. 依次尝试右上、右下、左上、左下等候选位置
5. 与已接受标签碰撞时尝试下一位置
6. 仍冲突则隐藏低优先级标签
7. 选中与悬停标签始终保留，并压低附近标签

标签布局需要节流，不在每一帧完整重新计算。相机稳定后执行精确布局，运动期间使用简化布局。

## 七、时间卷轴交互

### 拖动开始

- 进入 `isTimelineDragging`
- 记录起始范围与指针位置
- 暂停自动旋转
- 提升时间轴把手层级

### 拖动过程中

- 更新 `previewRange`
- 刻度带按位移滑动
- 卷轴下端产生轻微张力
- 坐标以透明度和极小尺度过渡预览
- 标签跟随坐标更新
- 聚类使用轻量近似结果
- 统计数字可以延迟更新

### 释放时

- 使用 spring 或 easing 完成轻微回弹
- 将 `previewRange` 写入 `committedRange`
- 执行精确筛选与聚类
- 更新 URL 和统计
- 恢复允许的地球惯性

### 键盘与输入

- 左右方向键微调年份
- PageUp/PageDown 大跨度移动
- Home/End 到范围边界
- 输入框支持负数表示 BCE
- 禁止公元 0 年
- 输入无效时保留上一次有效值并显示可读错误

## 八、筛选联动

来源、文化意义和对象类型筛选变化时：

- 坐标在 180–320 ms 内淡入淡出
- 标签同步更新
- 聚类数量平滑变化
- 不重置相机
- 不重置时间范围
- 不关闭当前详情，除非当前条目已不符合筛选

如果当前详情条目被筛掉，应提示并关闭详情，恢复地图状态。

## 九、动态效果参数

建议初始参数：

- hover: 120–180 ms
- marker fade: 180–320 ms
- label fade: 120–220 ms
- detail drawer: 280–420 ms
- globe to region: 700–1000 ms
- timeline rebound: 180–280 ms
- selected marker pulse: 1.8–2.6 s，低幅度循环

这些参数可以参考 MotionSites 的成熟 motion pattern，但必须以本项目实际阅读体验为准。

## 十、低动态三维

低动态模式保留全部功能，调整为：

- 无自动旋转
- 无持续呼吸光
- 无时间轴回弹
- 过渡缩短
- 相机直接或短距离移动
- 材质高光固定
- 标签直接切换

## 十一、移动端

移动端：

- 限制可见标签数量
- 时间卷轴使用更大的触控把手
- 详情改为底部抽屉
- 同地点列表使用全宽底部面板
- 地球旋转与页面滚动手势必须区分
- 筛选栏可折叠
- 不自动进入二维

## 十二、无障碍

- 坐标必须有可聚焦的替代列表
- 键盘可以选择聚类和条目
- 屏幕阅读器能读出地点、数量和条目名称
- 时间轴有明确 aria-valuetext
- 详情打开后管理焦点
- Escape 逐层返回
- 颜色不是唯一状态信号
