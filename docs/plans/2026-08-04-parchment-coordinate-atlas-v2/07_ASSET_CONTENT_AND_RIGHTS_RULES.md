# 07 资源、内容与权利规则

## 一、基本原则

本轮以视觉与交互重构为主，不扩充未经核验的正式史料。现有演示条目继续保留 `contentStatus: "demo"`。

任何纹理、地图数据、字体、图片、视频、MotionSites prompt 或第三方组件，都必须能够说明来源、许可和用途。

## 二、羊皮纸纹理

优先顺序：

1. 程序生成纹理
2. 项目自行制作并保存源参数
3. 公共领域或明确开放许可纹理
4. 用户合法拥有并明确提供的资源

不得：

- 从搜索结果随意下载纹理
- 热链外部图片
- 使用无法确认许可的扫描纸张
- 将 premium MotionSites 背景直接纳入仓库

程序生成纹理需要在代码注释或文档中记录 seed、尺寸、噪声方法和输出用途。

## 三、地图数据

世界和地区边界必须来自可追溯数据源。仓库中需要记录：

- 数据集名称
- 版本或获取日期
- 许可
- 是否经过简化
- 简化工具和参数
- 覆盖地区

不得为适配界面手工扭曲边界，也不得把现代国家边界当作所有历史时期的唯一政治叙事。当前边界主要承担地理定位，应在界面说明其为导航层，不代表历史政治边界。

## 四、字体

优先使用系统字体或现有本地字体栈。不得从外部 CDN 热链字体。

如新增字体，必须确认再分发许可并记录。不得因为 MotionSites 模板指定某款 Google Font 就直接引入。

## 五、条目媒体

本轮坐标地图不依赖每条记录都有图片。详情面板中的媒体仍遵守：

- public domain
- CC license
- museum open access
- user-owned and authorized
- fair-use assessment with explicit limitation

每个媒体字段保留 rights、credit、source 和 alt。

无图条目使用档案型占位，不用无关装饰图替代。

## 六、MotionSites 资源

MotionSites 的公开页面、section 名称和通用交互概念可以作为研究参考。具体 premium prompt、代码、视频、字体、背景和图片只有在用户合法获取并明确提供后才可使用。

如果使用用户提供的 prompt：

1. 在执行报告记录 prompt 名称
2. 不把原始受限 prompt 全文提交到公共仓库
3. 只记录提取出的通用 motion pattern
4. 重新实现并改写为本项目语言
5. 检查依赖和许可

## 七、内容措辞

地图坐标标签只显示条目名称，不在地图上直接给历史人物附加现代身份分类。

详情面板继续显示：

- 来源
- 证据等级
- 解释风险
- 文化意义
- 内容状态

演示条目不得因视觉升级被误写成已核验馆藏。

## 八、历史边界说明

全球和地区地图使用现代地理轮廓作为浏览导航时，需在 Guidelines 或 Atlas 信息区说明：

> 地图边界用于当代地理定位，不代表条目所处历史时期的政治边界、领土主张或文化边界。

未来若加入历史边界图层，应作为独立研究和数据阶段，不在本轮仓促实现。

## 九、仓库资源目录建议

```text
public/atlas/
  geography/
    world/
    regions/
  textures/
  credits/
```

建议增加：

```text
public/atlas/credits/ASSET_MANIFEST.md
```

记录每项静态资源的来源与许可。

## 十、验收

- 所有新增静态资源都有来源记录
- 无外部热链成为核心依赖
- 无未知许可 premium 内容
- 纹理和地图数据可以离线加载
- demo 内容状态仍清楚可见
- 地图导航层不冒充历史政治边界
