# The Seam 功能检查与补齐记录

日期：2026-10-04。基于 `def58a2` 的 Gemini 重构结果；开发分支 `codex/the-seam-completion`。

## 已修复的缺口

1. 移除未经配置的默认投稿邮箱。新增 `.env.example`；缺少真实邮箱时明确显示尚未开放，不生成虚构 mailto。复制失败可手动复制。
2. 国家深链接、档案链接携带的国家上下文、刷新、前进与后退同步页面。恢复旧 `entry-*`、旧事件 URL，以及旧介绍、投稿、索引入口。
3. 修正无效的 Canvas 清理回调，保存实际观察位置与缩放。国家点击先聚焦后切为二维；区分拖动和点击。白色球体不再被默认色调映射渲染成灰色；显式设定白色背景。
4. 二维国家地图增加鼠标、触摸平移缩放与低干扰缩放按钮；按主要多边形适配大国，完整轮廓保留。国家归属使用地图空间包含判断，避免编辑元数据把坐标放到国家轮廓外。
5. 坐标聚合随缩放改变，数量明确；同坐标记录仍通过选择列表访问。键盘可打开二维坐标。
6. 移除档案面板遮罩，桌面压缩地图可视宽度；地图、时间轴和档案可以同时操作。手机底部面板保留上方地图。补齐正文排版、图片来源、地理精度说明和现代位置提示。
7. 时间轴使用当前年份、动态刻度、单年选择与键盘操作，跳过不存在的公元零年；约束范围不越界，收起与再展开显示全部时期并保留档案、国家和地图位置。
8. 增加 WebGL 能力检测和二维浏览入口，修复测试发现的异步 WebGL 初始化失败无法由普通 React 错误边界捕获的问题。弹窗支持 Escape、焦点循环与返回触发控件。
9. 删除“用国家重心冒充首都”的回退。补入固定版本城市与行政区划资源、来源记录；城市和行政区划按缩放出现，区划按国家加载，缺失图层不阻断地图。
10. 开启 TypeScript strict；移除实施代码与原测试中的 any。修复迁移脚本对已删除临时模块的依赖，更新 README 和分享元信息。

## 原稿保全

- 重构后的 13 条档案保留；正文、参考资料未删除。
- 完整恢复重构前 `d475573` 的 11 条档案原稿与 17 条事件原稿，存于 `src/data/legacy/`。原有 7 条待审说明仍保留。
- 17 条演示事件都能通过索引、地点待考或旧链接访问。保留原稿年份描述、摘要、来源与贡献者，未伪造可靠年代和坐标；这些字段为空，不能投放到地图或强行归入时代。
- 原稿档案保留需人工核查说明，现有近似坐标不会被表述成精确出生地或唯一文化发源地。
- 旧数据没有绑定可靠档案图片，只使用媒体占位卡；现存图片文件、文献链接和旧地理资源未删除。新详情支持后续填入有来源的真实图片。
- 核对方式为原稿字段保全与条目计数，没有执行哈希比对。
